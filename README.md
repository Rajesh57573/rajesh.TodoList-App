# 📝 Todo List App

A modern, responsive Todo List application built using HTML, CSS, and JavaScript to make daily task management simple and productive.

## 🌐 Live Demo

🔗 **[View Todo List App](https://rajeshtodolist-app.vercel.app/)**

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 🌙 Light and dark mode
- 🎨 Modern UI with smooth animations
- 📱 Fully responsive design
- 🔤 Google Material Symbols icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts & Material Symbols
